Learning Outcomes

By the end of this lab, you will be able to:

  • Navigate the Linux file system using both absolute and relative paths
  • Create, copy, move, and delete files and directories

Lab Instructions

Make sure to take a screenshot of each problem solved. You can use the clear command to make sure the terminal is focused on your current solution

  1. Use pwd command to display and record the absolute path of your current working directory.
  2. Create two new directories using mkdir
  3. Use touch command to create five files in your home directory
  4. Navigate into one of the directories using cd
  5. Move one file from your home directory into your current folder using a relative path
  6. Use ls to confirm it moved
  7. Move another file from your home directory into the folder using an absolute path
  8. Use ls to confirm it moved
  9. Create a duplicate of one file in your folder and name the copy FILENAMEbackup using the cp command and relative paths
  10. Delete one file in your home folder using rm
  11. Perform a long listing ls -l of the home directory to view the final file details and permissions

Deliverables

A document containing the exact commands used for each numbered step, include clearly labelled screenshots of solution showing the successful execution of these commands as proof of testing. Your screenshots must show your prompt with your username, or a note with your name and the term.
