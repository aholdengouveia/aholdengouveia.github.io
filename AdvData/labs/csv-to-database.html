How it works

This page does two things:

  • Turn a CSV file into a database: makes a SQLite database file with one table, which you can open in SandboxSQL using Load a Database, or in any other SQLite tool.
  • Turn query results into a CSV file: runs a query on your database file and downloads the results as a CSV file, which you can open in any spreadsheet tool, such as Google Sheets or Excel, to make charts.

Everything happens in your browser. Your file isn't uploaded anywhere, and you don't need to install anything or make an account.

Turn a CSV file into a database

  1. Choose your CSV file.
  2. Check the table name and the number of rows to keep.
  3. Select Convert, check the summary, then download your database.

      How data types are chosen

      • INTEGER: every value in the column is a whole number.
      • REAL: every value is a number, and some have decimals.
      • TEXT: anything else. Numbers that start with 0, like ZIP codes, stay as text so the 0 isn't lost.

      Empty values become NULL, which means unknown. Column headings are changed to names that work in SQL: spaces and symbols become underscores, and a heading that starts with a number gets col_ in front. A table name that starts with a number gets data_ in front.
