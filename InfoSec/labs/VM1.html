Learning Outcomes

By the end of this lab, you will be able to:

  • Install virtualization software and create virtual machines
  • Install Linux Mint and Kali Linux in virtual machines
  • Configure virtual machine settings, such as memory and storage

Lab Instructions

You'll be setting up two virtual machines: Linux Mint, a beginner-friendly desktop Linux, and Kali Linux, which comes with many of the security tools used later in this class. The software and guides are all linked under Resources.

Apple Silicon Macs (M1 or newer): the regular downloads won't run on these Macs. You'll need the Apple Silicon version of VirtualBox, or UTM, with the ARM64 version of Kali. Linux Mint doesn't have an ARM64 version, so check with me for an alternative.

Screenshots

This lab asks for 6 screenshots. Each screenshot should have your name, term, and year. One of the easiest ways to do that is make a text document with your name and term/year on your computer and save it to use all term. Any screenshots that don't include this information won't be counted.

Set up VirtualBox

  1. Download and install VirtualBox, or another virtual machine program you prefer.

Install Linux Mint

  1. Download Linux Mint. Any desktop edition is fine.
  2. In VirtualBox, create a new virtual machine and use the Mint download to start it.
  3. When Mint starts, double click the Install Linux Mint icon and follow the steps. The Linux Mint installation guide can help if you get stuck.
  4. You'll make a username and password during the install. Don't lose them! If you do, you'll need to reinstall the whole virtual machine.

Install Kali Linux

Choose one of these two ways to set up Kali:

  1. Easier: download Kali's ready-made VirtualBox image, and import it by following Kali's guide. The default username and password are both kali. Change the password after you log in.
  2. Full install: download the Kali installer, and follow Kali's guide to installing it in VirtualBox. You'll create your own username and password during the install.

If the full install shows an error about the network mirror, continue without it. After the install finishes, follow Kali's guide to setting up its package repositories.

Kali no longer uses the root account by default, so log in with your own user. When a command needs admin rights, put sudo in front of it.

Check your settings

  1. Once each install is finished, open the virtual machine's Settings in VirtualBox, and go to Storage. Make sure the installer file (the ISO) has been removed, so the virtual machine starts from its own virtual hard disk. If you imported Kali's ready-made image, there's no ISO to remove.
