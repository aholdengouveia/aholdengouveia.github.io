Where to Go Next

Learning outcomes:

  • Identify cybersecurity career paths, and the skills each one needs
  • Compare security certifications by level, cost, and which roles they fit
  • Find legal, ethical ways to keep practising skills, such as labs, capture the flag events, and bug bounty programs
  • Create a personal learning plan for your next steps in security

  • Career Paths
    • Blue team: SOC analyst, incident responder, threat hunter
    • Red team: penetration tester, red teamer
    • Governance, Risk, and Compliance (GRC): auditor, risk analyst
    • Other paths: security engineer, cloud security, application security
    • CyberSeek's career pathway shows common entry level, mid level, and advanced roles, and how people move between them
  • Certifications
    • Entry level: CompTIA Security+
    • Next steps: CompTIA CySA+ for blue team, and CompTIA PenTest+ for red team
    • Advanced: OSCP, GIAC certifications, and CISSP, which needs several years of work experience
    • Compare the cost of the exam, any required training, and how long the certification lasts before you need to renew it
    • Check job postings in your area to see which certifications employers actually ask for
  • Where to Find Job Postings
    • CyberSeek's job heat map: how many security jobs are open in each state, and which certifications they ask for
    • USAJOBS: US government jobs, including many entry level security roles
    • LinkedIn Jobs and Dice, which focuses on tech jobs
    • Search for job titles, not just "cybersecurity", for example "SOC analyst" or "security analyst"
  • Keep Practising, Legally
    • Only test systems you own, or have written permission to test. Ethics is always important in this field, as we covered in the Ethics topic
    • Guided practice sites: TryHackMe and Hack The Box
    • Web application practice: PortSwigger Web Security Academy, which is free
    • Linux and command line practice: OverTheWire wargames
    • Build a home lab with virtual machines, so you can break things safely
  • Capture the Flag (CTF) Competitions
    • Teams or individuals solve security puzzles to find hidden "flags"
    • picoCTF is beginner friendly, and keeps past challenges up to practise on
    • CTFtime lists upcoming CTF events around the world
  • Bug Bounty Programs
    • Companies pay for vulnerabilities found within their published rules
    • Platforms: HackerOne and Bugcrowd
    • Always read the scope and rules first, the same as the rules of engagement for a pen test
    • HackerOne's disclosure guidelines explain how to report what you find responsibly
  • Build Your Portfolio
    • Write-ups of labs and CTFs you've done, without spoilers for challenges that are still running
    • A GitHub with your scripts and notes
    • Your work from this course, such as audits and incident reports, with anything sensitive removed
  • Stay Current
    • Security news: Krebs on Security
    • Podcasts: Darknet Diaries, true stories from the dark side of the internet
    • Local meetups: BSides events, OWASP chapters, and DEF CON groups
  • Ethics Is Always Important
    • The skills from this course can do real harm, so permission and scope always come first
    • If you're not sure whether something is allowed, ask before you do it

Suggested Activities and Discussion Topics:

  • Activity: find 3 job postings for a security role you're interested in, using the job sites above. List the skills and certifications they ask for. What shows up in all 3?
  • Activity: write a 6 month learning plan with one certification, one practice platform, and one community to join. Explain why you chose each one.
  • Activity: complete one beginner room on TryHackMe or one challenge on picoCTF, and write it up as if it were going in your portfolio.
  • Discussion: blue team, red team, or GRC? Which path appeals to you most, and why?
  • Activity: use CyberSeek's heat map to look up security jobs in your state. How many are open, and which certification is asked for most?
  • Discussion: you find a vulnerability on a website that doesn't have a bug bounty program. What should you do, and what shouldn't you do?
