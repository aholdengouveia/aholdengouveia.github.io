Classes

Every course here has learning outcomes for the whole course and for each week, plus my videos, slides, and the resources I've collected. You're welcome to use these materials, just give me credit.

Introduction to Linux

Never used Linux before? This class starts at the very beginning: what Linux is, who uses it, and how to get around the command line. You'll set up a virtual machine to practice in, learn everyday commands, file permissions, and networking basics, then write your first shell scripts with variables, conditionals, and loops.

Introduction to Data

Data is for everyone, not just data scientists. This class covers how data is collected, kept accurate, and organized into databases, then gets you writing SQL, including table joins. We finish with how data is used and misused, how to visualize it well, how to keep it secure, the laws that protect it, and what "big data" means.

View details »

Introduction to Security

Security isn't just for tech people. This class covers what everyone should know to protect themselves at home and at work: passwords and multifactor authentication, malware, social engineering, privacy, encryption, web security, and what to do after a data breach. Along the way we look at the ethical questions security raises, with hands-on labs in a safe environment.

View details »

Advanced Security

For people ready to take security further. We cover the topics on ethical hacking certifications: penetration testing and its tools, reconnaissance and OSINT (and how to defend against it), enumeration, and exploitation, including web exploitation. Then we switch sides to firewalls, hardening, audits, security frameworks, incident response, and disaster recovery, and finish with where to go next in your career.

View details »

Advanced Database Management

For people heading into database work. We go beyond the basics with schema design, query optimization, and documentation, then look at what happens when SQL isn't the answer: NoSQL, choosing the right database for the job, and scaling both. We finish with big data, visualization, and reporting. All the labs run in your browser.

View details »

Linux Administration

For people heading into system administration. You'll build and run a small network of virtual Linux servers from the ground up: users, installs and updates, troubleshooting, networking, iptables, security, backups and disaster recovery, virtualization, and containers. You'll also get comfortable with grep, awk, sed, and regular expressions, write real technical documentation, and build a portfolio to show employers.
